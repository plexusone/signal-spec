## [v0.1.0] - 2026-05-17

### Highlights

- Initial release of signal-spec with core types, JSON schemas, XLSX export, and CLI

### Added

- Core `Signal` type for atomic operational observations from external systems ([`c95faed`](https://github.com/plexusone/signal-spec/commit/c95faed))
- Core `RootCause` type for persistent clustered operational issues with lifecycle states ([`e539bba`](https://github.com/plexusone/signal-spec/commit/e539bba))
- Core `Remediation` and `ValidationSignal` types for tracking corrective actions and efficacy ([`569a2f5`](https://github.com/plexusone/signal-spec/commit/569a2f5))
- Common types: `Severity`, `Domain`, `Entity`, `SourceSystem`, `Tag` with kebab-case validation ([`6b27bf2`](https://github.com/plexusone/signal-spec/commit/6b27bf2))
- JSON Schema generation from Go types with enum constraints ([`002c8b1`](https://github.com/plexusone/signal-spec/commit/002c8b1))
- XLSX report generation with Domain Summary and Root Causes sheets ([`18f8979`](https://github.com/plexusone/signal-spec/commit/18f8979))
- Leader mapping support for area/execution leader assignments ([`18f8979`](https://github.com/plexusone/signal-spec/commit/18f8979))
- CLI with Cobra: `report`, `schema generate`, `validate` commands ([`9c285bc`](https://github.com/plexusone/signal-spec/commit/9c285bc))
- Tag validation using `mogo/text/stringcase.IsKebabCase()` ([`6b27bf2`](https://github.com/plexusone/signal-spec/commit/6b27bf2))

### Documentation

- Example JSON files for signals, root causes, remediations, and leader mappings ([`42812e8`](https://github.com/plexusone/signal-spec/commit/42812e8))

- Architecture documentation with data flow and design principles ([`2da5998`](https://github.com/plexusone/signal-spec/commit/2da5998))

### Tests

- Unit tests for RootCause type and lifecycle states

- Unit tests for export package including XLSX generation
