## [v0.2.0] - 2026-07-25

### Highlights

- 5 new product signal types for capturing customer and market intelligence: enhancement_request, competitive_gap, competitor_launch, analyst_finding, market_observation
- `pkg/ref` package with `TypedRef` for cross-repo entity references (customer, capability, market, competitor, analyst-report)
- Deterministic signal fingerprinting via `ComputeFingerprint()` for deduplication
- Embedded JSON schemas via `go:embed` for runtime schema access without file I/O

### Added

- 5 new `signal.Type` values for product intelligence: `enhancement_request`, `competitive_gap`, `competitor_launch`, `analyst_finding`, `market_observation` ([`bb99750`](https://github.com/plexusone/signal-spec/commit/bb99750))
- Metadata key constants for enhancement signals: `MetaVotes`, `MetaSubscribers`, `MetaOrganizations`, `MetaCustomers`, `MetaOpportunities`, `MetaEstimatedARR` ([`bb99750`](https://github.com/plexusone/signal-spec/commit/bb99750))
- Metadata key constants for cross-repo references: `MetaCustomerRef`, `MetaCapabilityRef`, `MetaMarketRef`, `MetaCompetitorRef`, `MetaAnalystReportRef` ([`bb99750`](https://github.com/plexusone/signal-spec/commit/bb99750))
- `DerivedMetrics` struct for computed scores (frustration, momentum, reach, urgency) excluded from fingerprinting ([`bb99750`](https://github.com/plexusone/signal-spec/commit/bb99750))
- `pkg/ref` package with `TypedRef` type and `Parse`, `Validate`, `ValidateStrict`, `ValidateSlug` functions for `{type}:{slug}` cross-repo references ([`4d66220`](https://github.com/plexusone/signal-spec/commit/4d66220))
- `Entity.Ref` field for linking signal entities to external repository definitions via typed reference ([`c1f41d9`](https://github.com/plexusone/signal-spec/commit/c1f41d9))
- `signal.ComputeFingerprint()` returning a deterministic SHA-256 digest of a signal's identity fields, excluding mutable/derived fields ([`fac3650`](https://github.com/plexusone/signal-spec/commit/fac3650))
- `schema/` package with `go:embed` directives exposing `SignalSchema`, `RootCauseSchema`, `RemediationSchema`, and `ValidationSignalSchema` as `[]byte` ([`6616d53`](https://github.com/plexusone/signal-spec/commit/6616d53))

## [v0.1.0] - 2026-05-17
